# Portal Canal do Canedo
Aprovado pelo usuário em 10/11/2026: página inicial explicativa com acesso às quatro análises existentes.
Alternativas: uma página longa tornaria quatro bases interativas difíceis de navegar; um portal mantém cada análise independente e dá contexto antes de entrar.
Estrutura: início, simulação, horários, última rodada e clássicos. HTML estático, caminhos relativos compatíveis com GitHub Pages, sem novas dependências. Manter dados, scripts e telas legadas.
Visual: roxo #400078, verde #00863a, fundo #ffffff, superfície #f4f1f8, texto #20172b, secundário #63596d. Montserrat local e sistema. Escala 4/8/12/16/24/32/48/64, raios 8 e 20. Sem animação decorativa. Tema escuro com fundo #18131f e texto #f5f0fa.
Layout escolhido: introdução em duas colunas com mapa de perguntas, seguida por quatro apresentações com links e guia de leitura. Alternativa: quatro cartões iguais com menor espaço explicativo.
Verificação: destinos internos, preservação dos scripts e visual desktop/mobile quando houver navegador disponível.
